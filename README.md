# Prompt Manager

Python으로 제작한 콘솔 기반의 나만의 프롬프트 관리 프로그램입니다. 프롬프트를 카테고리별로 정리하고 검색하거나, 자주 쓰는 항목을 즐겨찾기로 관리할 수 있습니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 프로젝트 폴더의 터미널에서 다음 명령을 실행합니다.

```bash
python3 main.py
```

화면에 표시되는 메뉴에서 원하는 기능의 번호를 입력하면 됩니다. 데이터는 프로그램이 실행되는 동안 유지되며, 종료하면 초기 상태로 돌아갑니다.

## 주요 기능

- 제목, 내용, 카테고리를 입력하여 프롬프트 추가
- 전체 프롬프트 목록 조회
- 카테고리별 프롬프트 조회
- 제목 또는 내용의 키워드 검색
- 프롬프트 전체 내용 상세 보기
- 즐겨찾기 추가 및 해제
- 즐겨찾기한 프롬프트만 모아 보기

## 카테고리

기본 카테고리는 `텍스트 생성`, `이미지 생성`, `영상 생성`, `페르소나`, `자동화`, `기타`입니다. 프롬프트를 추가할 때 원하는 카테고리를 직접 입력할 수도 있습니다.

## 데이터 구조

각 프롬프트는 제목(`title`), 내용(`content`), 카테고리(`category`), 즐겨찾기 여부(`favorite`)를 가진 딕셔너리이며, 여러 프롬프트는 리스트에 저장됩니다. 프로그램에는 기본 프롬프트 3개가 등록되어 있습니다.
